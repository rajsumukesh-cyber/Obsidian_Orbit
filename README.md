# Obsidian Orbit

A modern, full-stack application designed for managing, analyzing, and reporting on professional meeting insights.

## Key Features

- **Dynamic Dashboard**: Centralized hub to view, filter by attendees, and monitor meeting trends.
- **Meeting Management**: Interactive meeting cards with status tracking, note-taking, and detailed exploration.
- **Audio Intelligence**: 
  - **Real-time Recording**: Integrated microphone API for capturing live meeting audio.
  - **Action Item Extraction**: Automated analysis pipeline to extract actionable insights from meeting transcripts.
- **Advanced Analytics**: Visual trends for meeting sentiment scores powered by Recharts.
- **Reporting & Export**: Export meeting details, transcripts, and action items into professional, formatted PDF reports using jsPDF.
- **User Experience**: Built-in light/dark theme toggle for optimal viewing in any environment.

## Tech Stack

- **Frontend**: React 18+, TypeScript, Vite
- **Styling**: Tailwind CSS
- **Visualization**: Recharts
- **PDF Generation**: jsPDF
- **Backend API**: Node.js/Express
- **Animations**: Framer Motion / `motion`

## Deployment

The application is fully compatible with modern containerized environments.

1. **Install dependencies:**
   ```bash
   npm install
   ```

2. **Run locally (Development):**
   ```bash
   npm run dev
   ```

3. **Build for Production:**
   ```bash
   npm run build
   ```
